# Contributors

Everyone who has authored a commit in this repository's history, with the
number of commits under each name, most first. The history is kept as it
came: nothing is squashed or rewritten, so `git log` and `git blame` name the
author of every change, and commits brought in from other forks name the
commit and author they came from in their messages.

Names are as they appear in the commits. To regenerate this list:
`git shortlog -sn --all`.

The upstream projects this tree is built on are credited in the
[README](../README.md#credits).
